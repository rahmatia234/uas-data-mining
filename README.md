## 📌 Penjelasan Proyek
Aplikasi berbasis web ini dibuat menggunakan Streamlit untuk memenuhi Ujian Akhir Semester (UAS) mata kuliah Data Mining. Aplikasi ini terdiri dari dua fitur utama:
1. **Klasifikasi Diabetes:** Memprediksi risiko diabetes pasien menggunakan algoritma KNN, Naïve Bayes, dan Decision Tree berdasarkan atribut kesehatan.
2. **Clustering Gerai Kopi:** Melakukan analisis klaster pada lokasi gerai kopi menggunakan metode K-Means untuk memetakan distribusi lokasi dan mendeteksi zona sepi/kurang potensial.

## 💻 Instruksi Menjalankan Aplikasi (Lokal)
Jika ingin menjalankan aplikasi ini di komputer/laptop sendiri, ikuti langkah-langkah berikut:

1. Buka Command Prompt (CMD) atau Terminal.
2. Clone repositori ini dengan perintah:
   git clone https://github.com/rahmatia234/uas-data-mining.git
3. Masuk ke dalam folder proyek:
   cd uas-data-mining
4. Install semua pustaka (library) yang dibutuhkan:
   pip install -r requirements.txt
5. Jalankan aplikasi Streamlit:
   streamlit run aplikasi.py
